ABOUT

关于我

中职在读，同时是一人成军的独立开发者。

我是王孙阳，长夜拾星工作室（Nightglean Studio）的创始人。产品、编码、测试、发版，全流程自己一个人跑。

技术取向是「原生优先」：能用平台 API 就不引框架，能用系统工具链就不上构建系统。我笃信——依赖越少，出问题的面越小。

这个网站是我的零依赖数字名片：纯手写 HTML / CSS / JS，没有框架、没有构建、没有第三方请求，改完 git push 就发布。

PHILOSOPHY

我的信条

几条让我少踩坑、把东西做出来的原则。

01

少一层抽象，就少一类 bug

能用平台 API 就绝不引框架；每少一层，出问题的面就小一圈。

02

可复现的构建 > 聪明的构建

无缓存、无守护进程，构建时间可预期——比「快但玄学」更值钱。

03

先做出来，再优化

做出来比想清楚更重要；先跑通，再打磨。

04

只审计，不删除

工具应给出证据、把决定权留给人，而不是替人动手。
